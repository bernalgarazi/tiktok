## 1. CMS bat zer da?

CMS bat (Content Management System, edo euskaraz edukiak kudeatzeko sistema) webgune baten eduki digitalak sortu, editatu eta argitaratzeko software-tresna bat da. Berari esker, edozein pertsonak kudeatu dezake webgune bat programatzen edo kodea idazten jakin gabe.

Tresna hauek prozesuak errazten eta bizkortzen dituzte: webgune bat abian jartzeko denbora eta kostuak murrizten dituzte, hainbat pertsonek batera lan egiteko aukera ematen dute, SEO bidez bilatzaileetan hobeto agertzen laguntzen dute eta luzapenen bidez funtzionalitate berriak gehitzeko bidea ematen dute.

Xehetasun gehiago [CMS](CMS) dokumentuan.

## 2. Aztertutako CMSak

### WordPress

Munduan gehien erabiltzen den CMSa da. Kode irekikoa eta doakoa, erabiltzeko oso erraza, plugin eta txantiloi ugari ditu eta komunitate erraldoi bat du atzean. SEOrako oso ondo prestatuta dago.

Dokumentu osoa: [WordPress](WordPress)

### Joomla

WordPress eta Drupalen arteko erdibidea. Kode irekikoa, edukiak kategoriatan antolatzeko sistema ona du, erabiltzaileak eta baimenak modu zehatzean kudeatzen ditu, eta txantiloi eta luzapenen bidez pertsonalizatu daiteke.

Dokumentu osoa: [CMSGarazi.txt](CMSGarazi.txt)

### Drupal

Proiektu handi eta konplexuetarako CMSa. Segurtasun maila altua, eleaniztasuna core-an bertan eta eduki egituratua sortzeko malgutasun handia. Administrazio publikoek eta unibertsitateek asko erabiltzen dute, baina ikasteko kurba handia du.

Dokumentu osoa: [Drupal](Drupal)

## 3. Konparaketa-taula

| | WordPress | Joomla | Drupal |

| **Merkatu-kuota** (webgune guztien artean) | % 40,2 | % 1,1 | % 0,6 |

| **Gehigarri kopurua** | Milaka (gehien) | Ertaina | Gutxiago |
| **Zertarako egokia** | Blogak, enpresa txikiak, dendak | Webgune ertainak, elkarteak | Erakunde handiak, administrazioa, unibertsitateak |

Merkatu-kuotaren datuak: W3Techs, 2026ko iraila.

## 4. Ondorioa

Ez dago "CMS onena" deiturikorik: proiektu bakoitzak bere beharrak ditu.

- **WordPress** aukeratuko genuke webgune txiki edo ertain bat azkar eta merke abian jarri behar bada.
- **Joomla** aukeratuko genuke erabiltzaile eta kategoria egitura landuagoa behar duen webgune batean, baina Drupalen konplexutasunik gabe.
- **Drupal** aukeratuko genuke eduki asko, hizkuntza asko edo segurtasun eskakizun handiak dituen erakunde baten webgunean.
